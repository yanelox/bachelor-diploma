\section{Введение}
\label{sec:Intro} \index{Intro}

В последние годы архитектура RISC-V привлекает всё больше внимания в академической и промышленной среде 
благодаря своей открытости и модульности. Модульность является одной из ключевых особенностей архитектуры
RISC-V. Архитектура состоит из базового набора целочисленных инструкций, который должен присутствовать
в любой реализации, и из дополнительных расширений, которые можно включать по необходимости. 
Одним из них является векторное расширение (RISC-V Vector Extension, RVV), предназначенное 
для эффективной параллельной обработки данных.

Разработка и отладка программного обеспечения для RISC-V с поддержкой RVV требует соответствующих инструментов.
Одним из таких инструментов является отладчик.

Отладчик GDB (GNU Debugger) предоставляет пользователю множество возможностей для ускорения и упрощения
процесса отладки. Однако на момент начала работы GDB имел ограниченную поддержку RVV, в частности
отсутствовала поддержка соглашения о вызовах для векторных типов, которое необходимо для
работы механизма вызова произвольных функций с помощью GDB, что, в свою очередь, затрудняло возможности
для анализа и отладки подобных функций.

Цель данной работы -- расширить функциональность GDB за счёт реализации поддержки вызова функций с 
использованием векторного ABI для архитектуры RISC-V. Это позволит разработчикам вызывать такие
функции вручную из GDB, корректно передавая аргументы в векторные регистры, получать и интерпретировать
возвращаемые значения в соответствии с соглашением о вызовах для векторных типов.

В процессе работы был проведён анализ соглашения о вызовах, рассмотрена структура внутренних компонентов GDB, 
отвечающих за передачу аргументов при вызове функций, а также реализованы необходимые изменения для корректной 
обработки векторных типов. Разработанная реализация была интегрирована в исходный код GDB и протестирована 
на наборе функций с различными комбинации векторных типов в качестве аргументов, что позволило убедиться 
в корректности ее работы.

Практическая значимость данной работы заключается в повышении уровня поддержки GDB для архитектуры RISC-V, 
что способствует более эффективной разработке и отладке программного обеспечения для данной архитектуры.

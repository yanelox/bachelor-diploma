\begin{center}
	\textbf{Аннотация} \\[0.3 cm]
		Реализация в отладчике GDB поддержки вызова функций с векторным ABI для архитектуры RISC-V \\
		\textit{Радькин Кирилл Алексеевич} \\[1 cm]
	\end{center}

	В рамках данной выпускной квалификационной работы была реализована поддержка вызова 
	функций с векторным ABI для архитектуры RSIC-V в отладчике GDB. В работе рассмотрены
	особенности архитектуры RISC-V и векторного расширения данной архитектуры, процесс
	генерации отладочной информации компиляторами GCC и LLVM для архитектуры RISC-V.
	Для выполнения поставленной цели в отладчике GDB была релализована возможность взаимодействовия
	с векторными типами и соглашение о вызовах функций для векторных типов RISC-V. Корректность работы
	реализованных возможностей была проверена в рамках тестовой инфраструктуры GDB с использованием
	99 специально написанных для этого тестовых сценариев.

\section{Отладчик GDB}
\label{sec:gdb} \index{gdb}

\subsection {Основная информация}
\label{gdb:general}

GDB (GNU Project debugger) -- отладчик, программа, позволяющая анализировать и управлять
исполнением другой программы для нахождения ошибок в коде.
GDB поддерживает отладку программ, написанных на следующих языках:

\begin{itemize}
	\item Ada
	\item Assembly
	\item C/C++
	\item D
	\item Fortran
	\item Go
	\item Objective-C
	\item OpenCL
	\item Modula-2
	\item Pascal
	\item Rust
\end{itemize}

\subsection {Основные возможности}
\label{gdb:powers}

GDB позволяет запускать программы под своим управлением, анализировать и управлять их
исполнением.

Одна из основных возможностей это остановка исполнения программы в некоторой точке.
GDB позволяет установливать специальные метки в программе -- breakpoint-ы (точки останова),
которая указывает, в каком месте следует остановить выполнение программы. Breakpoint может
быть привязан как к строке в коде, так и к опредленному адресу. Во втором случае исполнение
программы будет остановлено перед исполнением инструкции, расположенной по указанному адресу.

После остановки программы, GDB позволяет выполнять множество различных операций,
полезных для поиска ошибок в коде.

Например, GBD позволяет просматривать значение переменных и изменять их. Для низкоуровневой
отладки существует аналогичная возможность отслеживания и редактирования значений определенных
регистров.

Следующей важной возможностью GDB является просмотр информации о текущем стековом фрейме и
стеке вызова функций.

Также, весьма полезной функцией является вызов отдельных функций программы.

\subsection {Отладочная информация: DWARF}
\label{gdb:debuginfo}

Отладочная информация -- данные, которые компилятор вставляет в исполняемые файлы. Эти
данные позволяются GBD понять, какие существуют переменные, функции, их местонахождение,
как соотносяться между собой машинные инструкции и исходный код и т.~д.

DWARF -- это соврменный формат отладочной информации, который используется в компиляторах GCC
и LLVM и поддерживается GDB.

Стандарт DWARF разработан так, чтобы быть применимым к множеству существующих языков, а также
иметь возможности к расширению для будущих языков.

\subsubsection {DIE}
\label{gdb:dwarf:die}

Запись отладочной информации (Debugging Information Entry, DIE) -- это базовая единица
данных в формате DWARF. Записи отладочной информации хранятся в секции \texttt{.debug\_info}
и/или в секции \texttt{.debug\_info.dwo} объектного файла.

DWARF использует наборы таких записей, чтобы описать структуру программы. Каждая запись
состоит из тега (tag), определяющего тип описываемой сущности (например функция, переменная
или название типа), и атрибутов, задающих конкретные свойства.

Рассмотрим генерацию DWARF информации на конкретном примере. Здесь и далее для компиляции
я буду использовать LLVM Clang 19.1.0 (если не указано иное) для архитектуры RISC-V,
а для наглядного отображения DWARF информации -- инструмент llvm-dwarfdump.
Данный инструмент сканирует DWARF секции в
объектных файлах и выводит содержимое в удобочитаемом виде.

Итак, возьмем простую функцию с Листинга \ref{lst:simple_example} и посмотрим, какую
DWARF информацию генерирует для нее компилятор.

\begin{samepage}
\begin{lstlisting}[language=C++, caption=Пример простейшей функции, label=lst:simple_example]
int foo (char a, int b[3], float *c) {
	return 42;
}
\end{lstlisting}
\end{samepage}

Для данной функции будет сгенерирована следующая DWARF информация.

\begin{samepage}

На Листинге \ref{lst:simple_example_dwarf} можно увидеть тег \texttt{DW\_TAG\_subprogram},
указывающий на то, что данная запись описывает некоторую функцию. По тегу \texttt{DW\_AT\_name}
мы можем определить, что это функция с именем \texttt{foo}.

Атрибуты \texttt{DW\_AT\_low\_pc} и \texttt{DW\_AT\_high\_pc} описывают диапазон адресов в машинном
коде, в котором располагается данная функция.

Содержимое \texttt{DW\_AT\_frame\_base} описывает значение базового адреса фрейма данной
функции. Для данной функции адрес ее фрейма будет располагаться на регистре \texttt{x8}.

Для описания типа возвращаемого функцией значения, используется атрибут \texttt{DW\_AT\_type}
